# 🏢 M.S Services & Trading — Official Company Website

A professional and fully responsive official website built for a **government contractor company**. The website serves as the company's digital presence, showcasing their services, projects, and providing an interactive experience for visitors.

---

## 🚀 Live Demo
https://www.msservicesandtrading.com/

---

## ✨ Features

### 🌐 Company Website
- Complete **company profile** and information
- **Services showcase** — all company offerings
- **Projects portfolio** display
- Professional and modern UI design
- Fully **responsive** — mobile, tablet, desktop

### 🤖 FAQ Chatbot
- Built-in **interactive chatbot**
- Answers frequently asked questions instantly
- Improves user experience and engagement
- 24/7 available for visitor queries

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| Next.js | Frontend Framework |
| TypeScript | Type-safe Development |
| Tailwind CSS | Styling |
| Vercel | Deployment |

## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/taha12-ok/Official-Website-MS-Services

# Install dependencies
npm install

# Run development server
npm run dev
```
